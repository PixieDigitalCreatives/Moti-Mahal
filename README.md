# Moti Restro — Jaypee Greens (premium redesign)

Animated website concept for Moti Restro, Sun Twilight, Jaypee Greens, Greater Noida.

- **Stack:** React 19 + Vite 8, React Router 7, SCSS (Sass modules), GSAP 3.15 (ScrollTrigger, SplitText, DrawSVG, Flip) via `@gsap/react`, Lenis smooth scroll, StPageFlip for the menu book.
- **Figma:** https://www.figma.com/design/780Z6yiDs2ysx8fBqBIiHu — colour and type tokens, components, the 4-frame gate preloader storyboard and the top of the Home page.
- The earlier plain-HTML version is kept in `archive/vanilla-site/` for reference; it is not part of the build.

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in dist/
npm run preview  # serve the production build locally
```

It is a single-page app with client-side routes (`/`, `/menu`, `/story`, `/gallery`, `/visit`). Hosting must send every path to `index.html`; `public/_redirects` (Netlify) and `vercel.json` (Vercel) already do that.

## Pages

| Route | Highlights |
| --- | --- |
| `/` | gate preloader, hero, scroll-scrubbed manifesto with image pills, pinned horizontal signature dishes, bento grid, arch window that grows to full screen, velocity-reactive marquee, sticky legacy split, parallax CTA |
| `/menu` | **Book view (default):** leather-bound book that opens from a closed cover, real page curl, drag or swipe a page, arrows and ← → keys, contents and chapter pages that jump to a dish, one spread per dish (photo page with a 3D tilt on hover, detail page with description, composition, spice level, pairing and price). **List view:** classic sticky-category list. Toggle in the category bar; `?view=list` opens the list directly |
| `/story` | Scrubbed intro, sticky outlined chapter titles, counters, sideways image ribbon |
| `/gallery` | Filterable grid (GSAP Flip), parallax tiles, lightbox with keyboard support, expanding mood panels |
| `/visit` | Contact details, validated reservation form (opens WhatsApp with the request filled in), dark map, FAQ accordion |

## Motion

- **Preloader:** shows on the first visit of a browser session (`sessionStorage`). The gate's line art draws itself while fonts and the hero image load, the facade lights up, the doors open, and the camera zooms through the arch into the live hero. "Skip intro" is available, and visitors with reduced motion get a short fade.
- **Route transitions:** any internal link raises an arch-topped curtain, the route changes underneath it, and the curtain lifts as the new hero rises in (`src/context/Experience.jsx`).
- Custom cursor and magnetic buttons on mouse or trackpad only; touch devices get native behaviour.
- `prefers-reduced-motion` turns off smooth scrolling, pinning and scrubbed effects.

## Structure

```
index.html                 app shell (fonts, meta, JSON-LD, first-visit flag)
src/main.jsx, App.jsx      router + global layers (nav, preloader, curtain, cursor)
src/context/Experience.jsx preloader / curtain / hero-reveal orchestration
src/hooks/                 useHeroIntro, usePageReveals, useMagnetic
src/lib/                   gsap setup, Lenis, data-attribute reveals, preloader timeline, menu book engine
src/components/            Nav, Footer, Button, Icon sprite, PageHero, Preloader, Curtain, Cursor, menu/*
src/pages/                 Home, Menu, Story, Gallery, Visit, NotFound
src/data/                  menu.js (dishes), site.js (contact, nav, route titles)
src/styles/                main.scss → abstracts/ (tokens, mixins) · base/ · components/ · sections/ · pages/
src/assets/gate.svg        generated by tools/gate.mjs (npm run gate)
public/images/             optimised WebP photos (originals in assets-src/images)
```

Scroll animations are declared in markup with data attributes (`data-split`, `data-fade`, `data-stagger`, `data-parallax`, `data-scale-fade`, `data-scrub-words`, …) and bound per route inside a GSAP context, so everything is cleaned up when you navigate away.
